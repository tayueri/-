ネット広告 操作トレーニング Level 1
BETA 01 / iPhone Safari優先

■ この版の範囲
L1-1 記事内広告：押さずにそのまま読む
L1-2 記事に似たPR：PR/広告表示を手がかりに選ぶ
L1-3 画面下固定：閉じても、そのまま読んでもよい
L1-4 ポップアップ：普通の広告を×で閉じる
L1-5 時間差全画面：数秒待って「閉じる」
L1-6 動画広告風：数秒待って「広告をスキップ」

L1-6は本物の動画ファイルを使わず、静止画＋CSSのゆっくりした動きで動画広告風にしています。
音声はありません。

■ サイト構成
index.html  ：Site A「暮らしの台所帖」 L1-1〜L1-4
outing.html ：Site B「週末のおでかけノート」 L1-5〜L1-6

■ 教室用URL
通常開始：index.html
毎回まっさらな状態で開始：index.html?start=1
講師用リセット表示：index.html?teacher=1
まっさら＋講師モード：index.html?start=1&teacher=1

通常の再読み込みでは同じタブ内の進捗を保持します。
?start=1 でLevel 1進捗を消して開始します。

■ GitHub Pagesへのアップロード
このフォルダの中身を、現在の公開フォルダへ上書きアップロードしてください。
assets フォルダもそのままアップロードしてください。
script.js が直接扱いにくい場合は script-js.txt をダウンロードし、script.js に名前を変更して使えます。

■ STEP3.4からの変更
・旧Q1の通常ポップアップをL1-4として再利用
・旧Q2 / Q3はLevel 1の導線から外した
・Level 1は普通の広告への操作に限定
・赤い「NG！」方式を廃止し、目的に応じた中立フィードバックへ変更
・Site Bを追加
・L1-5 / L1-6に別ブランド、別写真を採用
・内部のID/class/画像ファイル名は広告ブロッカーを意識して中立寄りにしている

■ 実機確認の優先項目
1. iPhone SafariでL1-1〜L1-6を通しで完走できる
2. AdGuard ON + 高度な保護 ONで表示と操作が壊れない
3. L1-3の×が押しやすい / 広告を残してスクロールしてもクリアできる
4. L1-5の3秒後に「× 閉じる」が表示される
5. L1-6の5秒後に「広告をスキップ」が表示される
6. L1-5 / L1-6の広告本体を連打しても進行が壊れない
7. 再読み込み後も進捗が不自然に巻き戻らない
8. ?start=1 で最初から開始できる

■ まだ仮の部分
Site Bの記事一覧・通常記事の写真部分は、現在CSSによる仮ビジュアルです。
広告写真は確定素材を使用しています。
動作確認後、Site Bの通常記事用写真を1枚追加すると、サイト全体のリアリティがさらに上がります。
